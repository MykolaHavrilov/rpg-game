# Дані гри та збереження

## Файли

| Файл | Що в ньому |
|---|---|
| `core.js` | спільний об'єкт `RPG`, шлях до кореня гри, глобальні налаштування (режим показу бою, гучність) |
| `data/levels.js` | таблиці досвіду (загальна сума для кожного рівня 1–30) |
| `data/items.js` | усі предмети: назва, слот, характеристики, ціна; ціни торговця |
| `data/classes.js` | професії: характеристики, приріст за рівень, стартові атрибути, стартові речі й локація |
| `data/enemies.js` | вороги (характеристики, досвід, золото, здобич) і локації |
| `stats.js` | атрибути (Сила, Спритність, Інтелект, Витривалість, Дух) і що вони дають |
| `save.js` | IndexedDB (запасний варіант — localStorage), список/видалення сейвів, експорт/імпорт JSON, міграція |
| `character.js` | персонаж, характеристики, досвід, інвентар, сундук, зілля, відновлення, загибель, Храм, торгівля |
| `battle.js` | автобій: `RPG.simulateBattle(save, enemyId)` |
| `game.js` | логіка сторінок (за `<body data-page="...">`) |
| `menu.js` | кнопки «Назад» та вихід з гри |

## Підключення на сторінці

Файли — **звичайні скрипти** (не модулі), тому гра працює і подвійним кліком
по `index.html`, і через Live Server. Порядок важливий:

```html
<script src="../assets/js/core.js" defer></script>
<script src="../assets/js/data/levels.js" defer></script>
```

## Характеристики

Підсумок = база професії + приріст × (рівень − 1) + **бонуси атрибутів** + вдягнені речі.

| Атрибут | Що дає за 1 очко |
|---|---|
| Сила | +2 атаки, +0,5 захисту, трохи блоку фіз. шкоди |
| Спритність | +0,5 атаки, +0,5 швидкості, шанс криту, трохи блоку фіз. шкоди |
| Інтелект | +6 мани, +2 сили магії, +0,3 маг. захисту, +0,2 MP за 10 с |
| Витривалість | +10 здоров'я, +1 захисту, +0,5 HP за 10 с |
| Дух | +2 мани, +0,5 сили магії, +1 маг. захисту, блок маг. шкоди, +0,5 MP за 10 с |

- Старт: усі атрибути по 1. За кожен новий рівень — **3 вільні очки** (сторінка «Персонаж»).
- Шанси криту й блоку ростуть «м'яко» і мають стелю (крит ≤ 60%, блок ≤ 50%).
- Речі можуть давати і характеристики (`attack`, `defense`, `blockPhys`…), і атрибути (`str`, `agi`…).

## Бій

- Шкода = атака × (0,85…1,15) × 100 / (100 + захист цілі). Крит — ×1,5, блок — половина шкоди.
- «Іскра» (4 MP) = сила магії × 1,6 проти магічного захисту. Магічна зброя (посох) кидає її автоматично.
- Швидший б'є першим і має шанс (до 30%) на додатковий швидкий удар.
- Ворог для бою обирається з урахуванням рівня героя: сильніші трапляються рідше. Його видно ДО бою,
  можна «Шукати іншого ворога».

## Локації (`data/enemies.js → LOCATIONS`)

| ID | Назва | Тип |
|---|---|---|
| `home` | Домівка | старт; бій заборонено; сундук; +5% HP і MP кожні 10 с |
| `temple` | Храм | місце відродження; молитва за полеглих у групі |
| `village_start` | Ферма | бої: щури 1–3 рів., вовки 4–6 рів. |
| `tavern` | Шинок біля млина | шинкар: продає за 150%, купує за 50% |
| `forest_path` | Лісова стежка | закрито (`locked: true`) |
| `forest_cave` | Печера в лісі | закрито (`locked: true`) |

Щоб відкрити локацію — прибрати `locked: true` і вписати `enemies`.

## Відновлення HP / MP

Кожні 10 секунд: `hpRegen` / `mpRegen` (атрибути + речі). У Домівці додатково +5% максимуму.
Рахується і за час, поки гра була закрита (поле `character.regenAt`). Під час бою не діє.

## Зілля

| Зілля | Ефект | Де взяти |
|---|---|---|
| Мале / середнє здоров'я | 30 / 80 HP | шинок, вороги |
| Велике здоров'я | 200 HP | лише вороги 5–6 рів. |
| Мале / середнє мани | 20 / 50 MP | шинок, вороги |
| Велике мани | 120 MP | лише Білий вовк |
| Чарівне | 50% HP і 30% MP | дуже рідко (0,3–0,8%) з вовків |

## Загибель

1. Штраф досвіду = (сума `exp` усіх ворогів у бою) × 10. Рівень не знижується:
   досвід не падає нижче порогу поточного рівня.
2. Кожна вдягнена річ — 0,5% шанс зникнути. Максимум речей за одну смерть:
   1–10 рів. — 1, 11–20 — 2, 21–29 — 3, 30+ — від 3 до 4.
3. Герой відроджується в Храмі з 10% здоров'я та 0% мани.
4. Речі в сундуку й інвентарі не зникають.

Група (майбутнє): `save.party` — масив `{ name, dead, hp, mp, maxHp, maxMp }`.
`RPG.pray(save)` у Храмі відроджує полеглих з 10% HP і 0% MP.

## Приклади (усе через `RPG.`)

```js
const save = await RPG.loadCurrentGame();
const stats = RPG.calcStats(save);            // hp, attack, crit, hpRegen...
RPG.addAttrPoint(save, "str");                // вкласти вільне очко
const enemyId = RPG.pickEnemy(save.location.map, save.character.level);
const result = RPG.simulateBattle(save, enemyId);
if (result.win) RPG.applyReward(save, RPG.getEnemy(enemyId).exp, RPG.rollLoot(enemyId));
else if (!result.draw) RPG.applyDeath(save, result.enemyIds);
RPG.moveToChest(save, 0);                     // лише в Домівці
RPG.buyItem(save, "potion_hp_medium");        // лише в Шинку
await RPG.saveGame(save);
```

## Як додати новий предмет
1. Додати запис у `ITEMS` в `data/items.js` з новим унікальним ID.
2. Покласти картинку в `assets/img/items/` з тим ім'ям, що в полі `img` (бажано 128×128 PNG).
   Поки картинки немає, у клітинці показується назва предмета — нічого ламатися не буде.
3. Щоб він падав з ворогів — додати його в `loot` потрібного ворога в `data/enemies.js`.
4. Щоб продавався в шинку — додати ID у `LOCATIONS.tavern.shop` (і не ставити `noShop`).

## Правила
- ID предметів, класів, ворогів і локацій **ніколи не перейменовувати** (назву можна).
- Коли змінюєте формат сейву: збільшити `SAVE_VERSION` у `save.js` і дописати блок у `migrateSave()`.
  (Зараз версія 2: старі сейви отримують атрибути по 1 і вільні очки за вже здобуті рівні.)
- Після будь-якої зміни сейву викликати `await RPG.saveGame(save)`.
